# SteadyAPI Stock Market API

SteadyAPI is a multi-domain data-API platform whose Finance/Stock Market API provides real-time and historical stock market data, company financials, insider and institutional trading data, earnings, options data, and more across US and international markets. A single API key also unlocks crypto, real estate, sports, e-commerce, social media, travel, and web-scraping endpoints under one REST/JSON base URL.
